PHP-FPM Metrics Pipeline

Request path + how fpm-status flows through the exporter into Prometheus and Grafana

The stats source

  • • FPM itself serves /fpm-status (pm.status_path in docker/fpm.conf)
  • • It is a FastCGI endpoint on :9000, not a public web page
  • • nginx also proxies it at :8088/fpm-status for humans
  • • Counters: active/idle processes, listen queue, slow requests

The exporter

  • • php-fpm-exporter speaks FastCGI straight to tcp://app:9000
  • • Pulls /fpm-status?full&json on every Prometheus scrape
  • • Re-publishes it as phpfpm_* metrics on :9253/metrics
  • • PHP_FPM_SCRAPE_URI set in docker-compose.yml

Prometheus + Grafana

  • • Prometheus scrapes the exporter every 1s (prometheus/prometheus.yml)
  • • Grafana (symfony/symfony) queries Prometheus with PromQL
  • • Provisioned dashboard: PHP-FPM Performance Dashboard
  • • Watch it live during make ember-load or the k6 benchmarks
