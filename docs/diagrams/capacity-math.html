capacity is math, not guessing
the two pools every Laravel app runs, sized by the same idea: measure one unit, derive the count
WEB REQUESTS · PHP-FPM
max_children = RAM for PHP ÷ avg process size
16 GB box → 12 GB for PHP × 0.9 ÷ 255 MB → ~42 children
unit to measure: MB per worker under load
QUEUE JOBS · WORKERS
workers = (pending ÷ SLA seconds) ÷ jobs/s per worker
100 pending ÷ 60s SLA ÷ 10 jobs/s → 1 worker
unit to measure: jobs/s one worker sustains
too low = queues while hardware idles  ·  too high = swap, OOM, thrash
both formulas re-run when reality changes: traffic, payload size, deploys  ·  alert when observed drifts from derived
